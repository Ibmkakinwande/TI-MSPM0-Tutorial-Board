# TI MSPM0 Tutorial Board

My custom TI MSPM0 hardware design built from scratch in KiCad, following Phil's Lab tutorial. Features schematic capture, PCB routing, and manufacturing files.

## Board Specifications
- **Board Name:** MSPM0G3507 Development Node
- **Microcontroller:** Texas Instruments MSPM0G3507 (ARM Cortex-M0+, 80 MHz)
- **Layer Stackup:** 2-Layer PCB
  - **Top Layer:** Primary component placement, high-speed USB traces, and signal routing.
  - **Bottom Layer:** Solid ground plane (GND return paths) with minimal signal traces to preserve signal integrity.
