# TI-MSPM0-Tutorial-Board
My custom TI MSPM0 hardware design built from scratch in KiCad, following Phil's Lab tutorial. Features schematic capture, PCB routing, and manufacturing files.
Hey World!, This is my personal hardware design project where I built a custom development board around the Texas Instruments MSPM0 microcontroller.
I followed along with Phil's Lab #166 tutorial to learn professional schematic capture, multi-layer routing practices, and proper component placement in KiCad 9. Everything from the decoupling capacitors to the USB-C interface and onboard debugger layout is documented here so I can easily take it straight to fabrication.
